# Socket Programming Basics

## What this is
A basic client-server program built in Python
to understand how sockets work.

## How it works
- Server listens on port 8099
- Client connects and sends name to server
- Server receives and responds

## How to run
First run server:
    python server.py

Then run client in new terminal:
    python client.py

## What I learned
- How sockets work
- Client side vs Server side
- Sending and receiving data
- How IP and port work together

## Tech used
Python, Socket
